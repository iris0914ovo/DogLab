# PERSONALITY DATA｜32 种正式犬格 V1.0

## 模型与匹配实施约定

全部为原创娱乐角色，不是犬类行为结论或专业心理测量类型。向量是人工创作的角色原型，不是统计训练结果，也不宣称 32 型能穷尽人类人格。每条共用 BREED_DATA 的 breed ID，独立人格 ID 为 P001–P032。八维向量各值为 0–100 整数，固定顺序：**D01 社交续航、D02 边界雷达、D03 情绪回弹、D04 表达外放、D05 探索欲、D06 行动启动、D07 秩序需求、D08 关系修复**。

沿用 PRD：用户百分分数按题库逐维归一化；总距离 `distance = Σ abs(user[i] - model[i])`；匹配分 `Math.round(100 - distance / 8)`，界面称“行为倾向接近度”，不称概率或准确率。

PRD 未细分显示舍入与排序：本版先以未舍入分排序，再比较总距离，最后按 breed ID ASCII 升序排序；未舍入分与总距离等价，不能用显示整数制造随机结果。同频取排除主要犬格后的最近原型；互补以 `100-user[i]` 为目标，排除主要犬格后取最近原型。二者各自独立计算，可以是同一犬格，不额外排除同频结果。互补仅表示向量反向接近，不承诺现实关系适配。

报告编号为 `DPL-Pxxx`，代表角色档案，不是用户唯一编号。分享参数采用版本 `v=1`、breed ID 和按 D01–D08 排列的八个整数；导入需校验长度、范围、整数、ID 与重算结果一致性，非法参数给出重新测试入口。本地存储不包含身份资料。
