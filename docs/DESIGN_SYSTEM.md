# DESIGN SYSTEM｜原创互动杂志视觉系统 V1.0

## 1. 创意主轴：生活观察，犬格归档

将网站设计成一本可互动的城市生活杂志：封面引人进入，问题像编辑提问，结果像专属人物专访，图鉴像一份可以翻阅的索引。品牌完整写法为 DOG PERSONA LAB｜犬格研究所。使用编号、细线、放大标题、局部色块和原创犬只插画构成识别系统。LAB 是趣味观察的隐喻，不用白大褂、检验结论或医学认证包装娱乐结果。

原创字标方向：英文大写分两行排布，PERSONA 为视觉重心，中文署名沿基线排列；一条不闭合的观察框与小型犬鼻轮廓作为辅助图形。标志需后续独立绘制，本文件只定义方向，不宣称已有资产。不要复制知名宠物品牌的符号或杂志版式。

## 2. 色彩与使用比例

| Token | 色值 | 角色 |
|---|---|---|
| paper | #F5F0E6 | 温纸色底，约占 65% |
| ink | #20201D | 正文、线条、关键按钮，约占 20% |
| rust | #AA3D24 | 章节强调、交互重点，约占 8% |
| acid | #D8EF58 | 局部标注、进度和海报强调，约占 4% |
| mist | #C7D8DB | 插画背景与次要版面，约占 3% |
| white | #FFFFFF | 反白文字、必要的干净区域 |

比例是页面节奏指导，不是像素配额。正文用 ink/paper；rust 在 paper 上用于短标题或按钮时仍需实测对比度，浅底色只配 ink。禁止 white/acid、white/mist 作为小字组合。后续实现必须对普通文字达到 WCAG AA 4.5:1、大字和非文本交互边界达到 3:1 做实测；本阶段尚无浏览器对比度验收。状态不能只靠颜色区分，同时提供勾选、文字或线条变化。

不为 32 种人格各建一套无约束颜色。主品牌固定，每型可从 rust/acid/mist 中选择一个主辅色组合，保持同一个报告系统。

## 3. 字体与层级

中文使用系统无衬线字体栈：PingFang SC、Microsoft YaHei、Noto Sans CJK SC、sans-serif；英文使用 Arial、Helvetica、sans-serif。章节引语可使用系统衬线字体形成少量对比，不依赖第三方字体请求。后续若加入字体文件，需核对许可证并本地托管。

| 层级 | 桌面字号 / 行高 | 移动字号 / 行高 | 字重与用途 |
|---|---|---|---|
| 封面主标题 | 88–120px / 1.0 | 48–64px / 1.05 | 800，允许分行但不挤压 |
| 页面标题 | 56–72px / 1.1 | 36–44px / 1.15 | 700 |
| 题目、章节标题 | 32–40px / 1.3 | 24–30px / 1.4 | 600–700 |
| 导语 | 22px / 1.6 | 20px / 1.6 | 400 |
| 正文、选项 | 18px / 1.75 | 17–18px / 1.7 | 400 |
| 索引、注释 | 14px / 1.5 | 14px / 1.5 | 400–500 |

正文每行约 24–38 个汉字，长段落限制阅读宽度；英文索引用少量字距，中文正文不用全局拉宽字距。数字进度可用等宽数字。禁止以 10px 小字承载关键内容。

## 4. 网格、间距与边界

最大内容宽度 1280px，桌面左右留白至少 48px，12 列网格、24px 沟槽。768–1023px 为 8 列、24px 外边距；小于 768px 为 4 列、20px 外边距、16px 沟槽。320px 窄屏可缩至 16px 外边距，保持内容不溢出。常用空间阶梯 4/8/12/16/24/32/48/64/96px。

正文与插画采用有理由的不对称比例，例如桌面 7:5，章节间以 1px ink 分割线、编号或整幅色面切换。圆角只用于真正需要的控件，通常 0–4px；标签也可用直角。不用悬浮阴影堆积层级，不将每个内容段装进独立容器。固定导航不得遮挡标题和键盘焦点。

## 5. 首页：杂志封面

顶栏为字标、图鉴和关于入口；主区用大标题“如果你的性格是一只狗”，配一组有叙事关系的原创角色插画与刊号 DPL / VOL.01。标题、插画和导语形成视觉张力，不复制营销模板的居中大标题加三张卖点卡。

主按钮“开始我的犬格测试”，旁注“24 道情境题 · 约 2–3 分钟 · 无需登录”。次入口“翻阅犬种图鉴”为文字链接。下方以三段横向编辑条目说明“回答生活情境 / 得到八维画像 / 发现你的犬格”，移动端顺序阅读。测试说明与娱乐免责声明入口应可见，不藏在极小页脚。

## 6. 测试页：编辑式问卷

顶部显示 Q01 / 24、细线进度及可读的完成数量。题号可以放大作版面锚点，题干位于左侧阅读区，桌面右侧留给小插画或留白，移动端先题干后选项。

四个选项是一组纵向单选行，以 A/B/C/D、正文和横分割线构成；不使用四张圆角白卡。整行可点击，最小高度 56px，选项可自然换行。选中时显示实心字母标记、明显侧线和局部浅色底，不能只改颜色。题目分值不显示。

默认选中后由“下一题”继续，不自动跳转；支持上一步修改且不丢答案。最后一题显示“查看我的犬格报告”。未选择时下一步不可用并提供可理解状态，不弹惩罚式提示。焦点与读屏需包含题干、单选组和选项文本；切题后将焦点移到题目标题。重新开始先确认会清除的进度。

## 7. 结果页：人物专访与报告海报

开篇使用档案编号、角色称号、大幅犬只肖像、犬种中英文名称、接近度与台词。正文按核心描述 → 三个标签 → 优势与隐藏属性 → 容易踩的坑 → 社交/情绪/关系 → 相处建议 → 八维画像 → 同频和互补的顺序组织。章节用编号和分割线，不把十个字段变成十张信息卡。

SVG 雷达图采用相同的 D01–D08 顺序，D01 在上方，从顶部顺时针排列。标尺 0/25/50/75/100，细灰网格、ink 数据线、低透明 acid 面；标签不能遮挡数据。同步提供八项数值的文字列表，不能依赖图形或色觉理解。显示用户向量，角色原型数据仅供算法，不冒充用户画像。

同频与互补为两个对照专栏，角色缩略插画配短解释和“浏览犬格”链接，移动端纵向排列。明确“向量接近 / 反向倾向”，不宣称最佳伴侣或关系预测。

分享区含复制链接、下载 PNG、原生分享、重新测试；原生分享不可用时显示复制入口。导出海报建议 1080×1440px，包含品牌、角色、肖像、台词、用户八维分数和娱乐说明；长文本在网页保留，不强行塞进海报。导出只使用可安全绘制的本地资源，失败时给出重试提示，不下载空白图。本阶段无导出实现或验收。

## 8. 图鉴：可检索索引

目录标题突出 120 SPECIES ARCHIVE，并说明本站收录粒度不等同权威统一品种数量。搜索支持中文、英文；分类标签使用 BREED_DATA 的编辑分类。搜索框有永久标签，不只依靠 placeholder。结果数、清除筛选和空状态明确。

桌面使用索引行：小型独立插画、编号、中英文名称、分类及正式犬格标记，以细线形成阅读节奏；可按首字母或分类浏览，不采用电商商品瀑布卡片。移动端每行先名称和插画，再显示分类与标记，按需进入详情。详情显示毛发、体型、事实简介与独立标注的娱乐旁白，正式犬格额外链接完整人格档案。返回保留搜索、筛选及滚动位置。

## 9. 插画系统

120 种犬种各需一张原创全身形象；32 种正式犬格另需可裁切的报告肖像构图，可由同一角色原画扩展，不用同一底图简单改色凑 120 种。风格为平涂剪纸感搭配轻微手绘线，ink 轮廓、2–4 个主体色、有限纹理、不使用拟真照片滤镜。表情有性格，但不把低分角色画成坏人。

统一基准画布 1024×1024，主要轮廓距边至少 10%，视线朝向与重心允许变化。每只需保留耳型、口吻比例、身体轮廓、尾型和典型毛纹的识别点；不以相同圆头模板代替犬种差异。自然耳尾优先，不添加裁耳断尾效果。主插画无外部投影和写实背景，海报可单独叠加品牌色面。

建议资产命名 `{slug}-full.svg`、`{slug}-portrait.svg`，同源 PNG 备用；记录作者、生成或绘制过程、许可、版本和人工复核状态。最终发布前检查跨角色一致性、犬种识别、版权及导出兼容性。不借用在世艺术家专属风格，不复制第三方现成犬只角色。本阶段仅规范，不生成资产。

## 10. 响应式、交互与可访问性

移动优先，320/390/768/1280px 作为后续检查宽度，200% 缩放不丢内容。按钮触控区至少 44×44px，相邻控件留至少 8px。正文和长英文 slug 可换行，不用缩小字号掩盖溢出。交互元素有可见 focus-visible（2px 线与间隔），选中、悬停、禁用、错误均有文字或形状区别。

图像提供描述性替代文本；装饰图不重复朗读。导航与表单使用语义化结构，支持全键盘操作。动态进度用适度的可访问通知，不每次播报整页。遵循 prefers-reduced-motion，常规过渡 120–200ms，禁用闪烁、强制滚动、视差和无意义加载动画。错误状态优先局部原位说明，不清空答案。

## 11. 禁用清单与验收

禁止 SaaS Dashboard、后台统计面板、满屏白色圆角卡、Bento Grid、大面积阴影、商城商品卡模板；不得把问题和每个选项分别装入圆角白卡。禁止直接套用 shadcn/ui、Ant Design、MUI 默认视觉；本项目按 PRD 使用原生 CSS 和语义控件。

后续视觉验收依次看封面辨识度、排版节奏、正文可读性、答题行选中状态、结果海报完整性、索引可检索性、120 角色一致性，再检查响应式、键盘与色彩对比。文档阶段仅确认规范与 PRD 一致，不能宣称页面已满足这些验收项。禁止本阶段初始化框架、实现页面或部署 Pages。
