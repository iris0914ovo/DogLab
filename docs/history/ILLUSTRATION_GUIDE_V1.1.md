# ILLUSTRATION GUIDE｜犬格角色统一生产规范 V1.1

## 依据与本批范围

以 PRD、QUESTION_BANK、PERSONALITY_DATA、BREED_DATA、CONTENT_GUIDELINES、DESIGN_SYSTEM 六份 V1.0 文档为唯一产品依据。本文件只细化生产参数，不更改犬种收录粒度、人格、维度或向量。本次为 Phase 2.3 前的视觉审核修订。用户转述 ChatGPT 已在对话中生成并审核六种代表犬样图，结论为整体方向通过、批量生产前需修改。样图尚未上传本仓库，本次未直接检视图片；不能据此宣称项目已有图像或单图批准，资产两种状态均保持 PLANNED。逐犬意见见 [ILLUSTRATION_REVIEW.md](ILLUSTRATION_REVIEW.md)。品牌标志为本批单独制作的 SVG 视觉提案，等待用户视觉审核。

## 01｜整体风格

风格定义为原创手绘剪纸感、现代绘本插画与 Editorial Design 的结合。保留深色轮廓、大面积色块与轻微纸感纹理，干净而有情绪，不走幼儿贴纸的统一圆头路线。角色拟人来自姿态、目光和节奏，不穿工作制服解释人格。犬种事实与虚构人格分离，不按向量高低画出好狗坏狗。禁止抄网站形象、知名 IP、插画师专属风格、照片写实、宠物摄影、塑料 3D、复杂渐变及戏剧光影。

## 02｜身体与头身比例

正式交付基础画布统一 1024×1024，高清母版允许保留原始分辨率。不同犬种不要求相同身体比例，必须保留真实耳型、口吻、身长腿长、尾型与被毛特征；比例可比较，但不统一解剖模板。定义 H 为不含耳毛的颅顶到下颌高度，站姿地面到颅顶的高度作为头身比；坐姿仍依据站姿骨架推导，不能按坐姿高度重新缩腿。一般角色总高约 3–4.5H，头部可相对真实形态放大约 10–15%，不做占身体一半的婴儿头。短腿、视觉猎犬、巨型犬依据形态单独调整。

第一批设计目标（为插画比例指导，不是犬业协会体态标准）：

| Breed ID | 犬种 | 站姿高度参考 | 轮廓首要差异 |
|---|---|---|---|
| B001 | 柴犬 | 约 3.3H | 紧凑躯干、小三角立耳、背上卷尾 |
| B002 | 西伯利亚哈士奇 | 约 4H | 腿较长、楔形头、浓密尾，不画柴犬式紧卷尾 |
| B003 | 金毛寻回犬 | 约 3.8H | 稍宽口吻、垂耳、顺落饰毛与长尾 |
| B004 | 边境牧羊犬 | 约 4.2H | 轻盈骨架、较窄头、半立耳、低垂长尾 |
| B005 | 威尔士柯基犬（彭布罗克） | 约 2.8H | 长身短腿、宽基大立耳；本角色选自然长尾 |
| B007 | 贵宾犬 | 约 4.4H | 本角色选标准体型，长腿细口吻、垂耳卷毛 |

贵宾不同规格仍共用 B007；长尾柯基不新增品种记录。其余 114 种后续需先从 BREED_DATA 提取事实特征，再建立比例草图，不从这六种复制身体。真实形态资料尚有待核验，审核时记录参考来源；不要把本规范的夸张比例当作真实体型数据。

## 03｜头部、五官和肢体

头部先定楔形、长窄形或宽方形再画五官；口吻要有侧向体积，用一块鼻梁面和一块口鼻面表现，不用贴在脸上的小圆点取代长口吻。鼻子用 ink 小多边形或柔角三角形，适当简化，不把品牌符号贴在每张脸上。

耳朵明确耳根位置、软硬和倾角；立耳保留两条外边与内耳小色块，垂耳随头部重力下落，半立耳有可读折点。保持自然耳形，不画裁耳。眼睛为小椭圆或短弧，1024 图上通常 12–22px 宽，深色为主；无巨大玻璃高光或人类睫毛，左右可有轻微表情差别但不解剖错位。

四肢先画肩胛/髋位置再画关节，前肢下段不凭空弯折；脚掌以一块轮廓加 1–2 条趾线简化。四足总数必须正确，遮挡腿仍应有合理身体连接。尾根接在骨盆后方，卷尾、镰尾、长饰毛尾、细长尾分别设计；不以通用螺旋替代。保留自然耳尾，不为审美添加断尾。

## 04｜犬种辨识方法

每只建立至少五项辨识记录：耳形、口吻、身躯长高关系、尾型、毛纹/毛长。至少三项必须是结构差异，不能五项全靠颜色。先做纯黑轮廓，再看无名称的脸部与全身；六只并排应能通过轮廓区分紧凑柴犬、长身柯基、轻盈边牧、长腿贵宾、浓毛哈士奇与垂耳金毛。无法区分时重做结构，不能只改色。

## 05｜线条与轮廓

以最终 1024px 交付图衡量，外轮廓统一以 10px 为基准（局部手绘变化控制在 8–12px），内部结构线以 5px 为基准（4–6px），表情线约 5px。高清母版按输出缩放比例同步放大线宽，同一批次不可随意切换粗细。线色 ink #20201D。连接与端点轻微圆润，保留有控制的不对称起伏（约 1–3px），不加双重草稿线或随机抖动滤镜。闭合填色无漏缝；肢体重叠仅保留必要接缝，避免同位置双线。缩略图减掉细纹，不简单加强锐化。

## 06｜色彩

沿用 paper #F5F0E6、ink #20201D、rust #AA3D24、acid #D8EF58、mist #C7D8DB。犬毛允许额外选取接近真实毛色的平涂色，每只 2–4 个主体色（不含 ink 线色），如金毛的赭金 #C99442 与浅金 #E7C783；这些是插画毛色，不新增 UI 品牌色。acid/mist 用于编辑背景或后期版面，不把所有狗染成品牌色。白毛用暖白填色且保留真实不透明像素，不能把白毛误删为透明。色盲/灰度下仍须可辨轮廓和毛纹大关系。

## 07｜毛发与材质

短毛用整洁大轮廓及少量转折；双层毛在颈、胸、尾各加 2–4 个毛簇；长饰毛用长短不一的平面切口；卷毛用 6–12 个有大小变化的团块建立轮廓，内部只留少量断弧。绳状、刚毛和无毛犬后续分别制定母图，不套用卷毛纹理。

纸感来自色块边缘与少量同色细粒，覆盖统一控制在主体面积约 3–5%，纹理明暗差保持轻微（建议约 5–8%），不靠大颗粒或脏污制造纸感；纹理用不透明颜色绘入主体，不能打穿 alpha。透明区域完全无纹理。阴影强度统一：只允许身体内部必要的低对比平涂结构暗面，建议与相邻色面的明度差不超过约 10%，不叠加多层半透明暗影，不画地面投影、环境遮蔽或渐变塑形。上述数值是后续绘制目标，未对缺席样图做像素测量。以首批修订后批准的六图作为后续线宽、暗面强度和纸感密度基准。禁止逐根毛、真实皮肤、油亮高光及毛毡摄影材质。纹理不得遮挡眼、鼻和品种标记。

## 08｜表情与姿态

以 PERSONALITY_DATA 的角色内容选一个动作主题，不把所有特征挤进一张图。柴犬可侧目自持，哈士奇可抬爪好奇，金毛可身体微前倾，边牧可安静专注，柯基可回头观察，贵宾可轻抬下颌。此为角色演绎，不是犬种行为断言。表达冷静不等于凶恶，热情不等于愚蠢。避免露牙威胁、流泪羞辱或夸张病态喘气；不依赖衣物、电子设备或人格文字让角色成立。

## 09｜全身图

单只完整犬只、轻微三分之四视角，保留耳尖、脚掌、尾尖。主体包围盒最长边目标约 819px，即画布的 80%，四周保留约 10% 安全边；包含线条与自然抗锯齿边缘，完整落在约 x/y 102–922 的安全区内。目标为近似比例，不为凑足尺寸裁耳裁尾。重心一般 x=512，可微偏不超过 40px；站姿角色优先统一承重脚底基线 y≈920（含边缘），长身短腿角色若高度不足仍按宽度约 80% 等比适配并向基线对齐，不拉高腿部。基线优先、上方允许更多留白，不能为强行居中破坏比例。坐姿不强行套用站姿腿长或拉高身体；必要时可按完整轮廓居中。长身犬以宽度适配，不能拉长腿来占满高度；高腿犬以高度适配。体型差异由解剖体现，不用同画布虚假表达所有犬只真实等大。

## 10｜报告肖像

仅 32 种正式犬格需要独立肖像交付。仍为 1024×1024，头、双耳与上胸完整，耳顶/侧边至少 103px 留白，胸部下缘收进画面，不在脸、耳、口吻上裁断。面部中心约 (512,440)，占画布宽 45–60%，长耳/长口吻优先完整保留。保持全身版眼鼻位置关系、毛纹和配色；可从高质量母图重构，不强行放大低清局部。本次六份 Prompt 都是全身测试，肖像尚未生产。

## 11｜图鉴缩略图

由审核后的全身母图派生 256×256 PNG，保持同一安全边与 alpha；网页预期 64–128 CSS px 使用，48px 下仍检查耳、口吻与尾部。减少内部纹理后再缩小，不另造一只角色。缩略图为派生物，不额外算入 120 只。未来路径 `public/assets/dogs/full/{slug}-thumb.png`，本阶段不创建。

## 12｜透明底与背景

正式 PNG 必须为真实透明背景的 RGBA，主体外部 alpha=0，主体内部（包括白毛、眼鼻、纹理和内部暗面）alpha=255，轮廓边缘保留自然抗锯齿所需的中间 alpha。不得通过全图半透明表现纸感，不得硬阈值切边导致锯齿。轮廓间真实空隙仍应透明。不能用白色、米色或棋盘格假装透明。不画地面线、投影、场景、色块边框、文字或水印。检查 paper、ink、mist 三种底上的边缘，无白边、黑边或误透明毛发。需要杂志色面时在后续版面叠加，不烘焙进角色。若生成工具不能输出 alpha，必须另行批准工作流并记录去底处理与复核，不能仅改扩展名宣布透明。

## 13｜导出规格

| 用途 | 格式 | 尺寸/画布 | 要求 |
|---|---|---|---|
| 高清源母版 | 保留工具原生格式或原始 PNG | 允许保留原始分辨率 | 保存完整源图，不以改尺寸或改扩展名伪造高清 |
| 正式全身与肖像交付 | PNG RGBA | 1024×1024，sRGB | 真实透明背景、主体内部不透明、自然抗锯齿、安全边约 10% |
| 可选矢量重绘母版 | SVG | viewBox 0 0 1024 1024 | 仅实际人工重绘后登记，无外链/脚本/字体依赖；不是本轮交付前提 |
| 图鉴缩略图 | PNG RGBA | 256×256，sRGB | 由验收后全身图派生，保留 alpha；不替代正式 1024 交付 |
| 评审合版 | PNG | 按需要 | 标注和背景只在合版层，不回写透明交付图 |

正式交付以 1024×1024 PNG 为准，替代 V1.0 的“最终 SVG＋PNG 备用”交付约定；现有六份正式产品文档不回写。高清源文件可保留原始尺寸，导出时等比缩放，再平移放入透明画布；不得分别缩放宽高、拉伸躯干或腿、压扁口吻来填满正方形。若源图过低清或结构不合格，回到绘制/生成环节，不用插值冒充高清。SVG 仅可作为真实矢量重绘的补充，不把 PNG 嵌入 SVG 冒称矢量；版本证据需明确实际格式与文件。

## 14｜命名、版本与记录

正式 PNG 计划路径：`public/assets/dogs/full/{slug}-full.png`、`public/assets/dogs/portrait/{slug}-portrait.png`；只有文件实际上传、检查通过后才能登记为实际文件。可选同名 `.svg` 只在真实矢量重绘存在时登记。slug 必须逐字取自 BREED_DATA，不按犬名重新翻译。草稿不覆盖批准文件，工作名可用 `{slug}-full-v01.png`，保留在工作区审核目录；批准后再将对应版本同步正式路径。

每次生产记录 Breed ID、Prompt 版本、工具/模型版本、实际日期、操作者、参考资料来源/许可、候选文件路径、SHA256、处理步骤和审核结论。没有调用工具就写“未生成”，不得伪造 seed、工具版本或版权审查。本次仅修订文档和生产计划，不发生 AI 图像调用、图片编辑或样图导入。对话样图的真实文件、工具版本与哈希当前均未获提供。

## 15｜AI Prompt 写作规范

结构固定为：角色身份与造型选择 → 耳口鼻和身体结构 → 毛发与固有色 → 动作表情 → 统一材质线条 → 画布透明底及安全边 → 禁止项。提供全名和 Breed ID 关联，但明确画面不出现文字；不传入八维数字让模型臆造性格，不使用其他艺术家/IP 名称。优先约束结构再描述气氛，使用一只狗、一个动作、一个视角。

[FIRST_BATCH_PROMPTS.md](FIRST_BATCH_PROMPTS.md) 的六个代码块是可独立使用的完整 Prompt；不得只复制犬种段而丢失公共约束。该文件保留为首轮历史 Prompt（`DPL-ILL-1.0`），未回写其中旧的 SVG 路径、720–800px 及姿态参数；下一轮生成前必须按本规范 `DPL-ILL-1.1`、正式 PNG 输出约定及逐犬审核意见编写新版本 Prompt，不能原样再次调用旧 Prompt。先完成六只修订和样图归档审核，再按下述小批量计划推进，不能直接生成其余 114 只；本阶段不调用图像工具。

## 16｜质量验收与状态

逐资产使用 PLANNED → GENERATED → REVIEWED → APPROVED；生产状态与人工审核状态分列。PLANNED=未制作/未审核；GENERATED=已有真实输出、未人工审看；REVIEWED=有人工意见但仍待批准；APPROVED=用户或指定审核者明确批准特定版本。脚本/AI 自检不是人工批准，退回时保留版本和意见，不伪造通过。用户转述的 ChatGPT 审核记录单独保留，并不等于素材已落库或人工批准。本仓库尚无样图，因此本批狗狗两列均为 PLANNED；方向通过不是六个文件全部 APPROVED。

验收必须检查：

1. 对照 Breed ID、名称、slug，核对至少五项形态，其中三项为结构；先看无标签轮廓，再看毛纹。
2. 骨架、肢体数量、耳根、尾根和眼鼻关系无错；无裁耳断尾暗示，无极端有害夸张。
3. 线宽、色数、剪纸感、有限纹理一致；六只不是同头同身换毛色。
4. 1024 正方形、安全边、全身与肖像范围、真实 alpha 和三底边缘均合格。
5. 在 1024/256/64/48px 检查可辨识性；正式 PNG 为 RGBA、主体内部不透明、边缘抗锯齿自然；若另交 SVG，再检查渲染与 PNG 一致且无外链脚本和伪矢量。
6. 文案语义不被表情歪曲，无 IP 挪用或艺术家专属风格模仿，来源与许可记录可追溯。
7. 由人工审阅角色一致性与品牌气质；明确批准前一律不标 APPROVED。

遇到额外肢体、错品种、同模版、假透明、IP 相似或关键结构不可辨，应退回重做，不用提高分辨率或改文件名掩盖。本次只修订规范和计划；不生成、导入或编辑狗狗图片，不开发网站，不自动进入 Phase 3。
