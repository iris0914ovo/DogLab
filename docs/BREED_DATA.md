# BREED DATA｜犬种图鉴 V1.0

## 范围与字段

120 条独立图鉴记录；B001–B032 参与正式测试，B033–B120 为普通图鉴。breed ID 是稳定关联键，slug 为小写 ASCII 连字符路径键，不以中文展示名关联。犬格与对应犬种共用 breed ID，编辑人格时不生成第二套犬种记录。

下面分类是本站浏览分类，不声称等同任何犬业协会的正式分组；各组织对品种、变体和体型的承认存在差异。本版将比利时牧羊犬四类型及粗毛/短毛柯利分别作为图鉴条目；贵宾犬、腊肠犬及墨西哥无毛犬各体型合并为一条。分类主要用于索引，不推断性格。

体型为编辑粗分类，不是精确身高体重标准；“多体型”表示品种包含多个尺寸。下列毛发与形态描述是犬种资料，不能推断个体健康、行为或养护难度。这里不提供未经核实的起源年代、血统史、寿命和疾病概率。事实编辑参考入口：[FCI 品种目录](https://www.fci.be/en/Nomenclature/)、[AKC 品种目录](https://www.akc.org/dog-breeds/)。本版为保守概述，未进行逐条外部来源核验；正式上线前由编辑按条目核对标准，不能把参考入口当作已完成核验的证据。

人格创作与事实资料分开：正式犬格详见 PERSONALITY_DATA；其余 88 种的“拟人旁白”仅为原创角色片段，不参与匹配，不描述真实犬只普遍性格。120 种均计划制作独立插画，本阶段无插画成品。
