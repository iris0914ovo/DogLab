# BRAND IDENTITY｜原创品牌标志提案 V1.0

## 设计逻辑

以 DESIGN_SYSTEM 的“不闭合观察框＋小型犬鼻轮廓”为基础，手工编写 SVG 路径：观察框右上角主动断开，rust 的短折角让观察仍有继续的空间；内部用宽弧三角犬鼻、两道留白与短口线建立犬只联想。没有试管、十字、白大褂、认证徽章或医学检测含义。

英文字标按 DOG / PERSONA LAB 两行排列，第二行成为视觉重心。英文字母用同一 56 单位高的原创几何骨架逐字构建，斜切转角与开放 G 呼应框线的留白，不调用商业 Logo 或现成品牌图标。中文“犬格研究所”在第一行与 DOG 共享基线，是固定署名，不压进辅助符号。

## 使用规则

主标志优先放在 paper，反白优先放在 ink；辅助符号可放在 paper 或 mist。保持原始比例，不拉伸、描边加粗、加阴影或放入圆角白卡。SVG 本身无底色，反白文件在白色背景无法清楚阅读不是缺失，应叠加深底检视。

完整字标建议最小展示宽 360 CSS px，此时中文字高约 12px；比这更窄的移动页眉使用独立符号，不强塞双语字标。独立符号最小建议 32px；此时外框线约 1.25px，16px 下的细节不作保证，不直接当最终 favicon。外部净空至少相当于符号画布宽的 1/8（32 单位）；文件内已有留白不应被自动裁除。结果报告和 1080px 海报可按内容宽度 400–600px 使用完整字标，主体不能压住犬种名称。

## 原创部分与字体许可

观察框、犬鼻辅助符号、英文字母路径和组合排版为本项目原生 SVG 设计提案，未使用外部 Logo、图标或角色素材。中文使用本机 Noto Sans CJK SC Bold 的五字轮廓，保留字形而非宣称原创汉字字库；已转为 SVG path，因此无需网络字体或终端安装字体。

字体来源为系统 `/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc` 中 SC 字面，许可与版权说明随 [NOTO-LICENSE.txt](../public/assets/brand/NOTO-LICENSE.txt) 保存（SIL Open Font License 1.1，含上游署名）。未复制完整字体文件。原创设计不等于已完成商标检索，本提案尚未进行商标注册或法律排他性确认。

## 实际验证记录

使用已安装的 Chromium 与 Playwright 在内存中离线渲染 SVG，未创建网站页面、启动应用或安装依赖。主标、反白和符号均成功渲染，中文轮廓可见；三文件 viewBox 均包含图形边界，PNG 渲染角像素 alpha 为 0。三个 SVG 均无 text/font 外部依赖、外部资源、脚本、滤镜与嵌入栅格。

已查看实际渲染合版，检查主标与反白的英文、中文、不闭合框与犬鼻。发现英文 N 的尖锐转角后已降低斜接限值并重渲染，避免突出的长尖角。以上属于制作自检，用户的视觉认可仍待进行。
