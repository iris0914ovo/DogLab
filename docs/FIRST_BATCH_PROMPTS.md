# FIRST BATCH PROMPTS｜六种代表犬视觉测试 V1.0

依据 ILLUSTRATION_GUIDE 与现有犬格资料。共享风格版本 `DPL-ILL-1.0`，每个代码块均为独立完整 Prompt，可直接复制，不必另外拼公共段落。当前仅写作 Prompt，六只制作与人工审核均 PLANNED，未调用图像生成工具、没有候选图片。全身通过后再单独规划对应肖像，不自动生成其余 114 只。

## 六图并排审核要点

先去掉名称和颜色比较轮廓，再检查面部与尾部。柴犬与哈士奇不能只换色；金毛必须有垂耳和饰毛，不能成为浅色边牧；柯基的长身短腿不可被姿态遮住；贵宾的细长口吻与卷毛耳必须和比熊区分。允许单张姿态不同，但线宽、色块密度、留白和眼睛尺度应保持同系列。真实候选图产生后记录文件、工具、时间、哈希与人工意见；本文件不预填完成结论。
