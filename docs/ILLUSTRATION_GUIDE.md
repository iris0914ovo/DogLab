# ILLUSTRATION GUIDE｜犬格角色统一生产规范 V1.0

## 依据与本批范围

以 PRD、QUESTION_BANK、PERSONALITY_DATA、BREED_DATA、CONTENT_GUIDELINES、DESIGN_SYSTEM 六份 V1.0 文档为唯一产品依据。本文件只细化生产参数，不更改犬种收录粒度、人格、维度或向量。当前交付规范、资产计划和六份 Prompt；狗狗图像尚未生成，全部 PLANNED。品牌标志为本批单独制作的 SVG 视觉提案，等待用户视觉审核。

## 01｜整体风格

原创现代互动杂志的扁平动物角色，剪纸般清楚的实色块、轻微手绘起伏、深色轮廓、有限纹理；干净而有情绪，不走幼儿贴纸的统一圆头路线。角色拟人来自姿态、目光和节奏，不穿工作制服解释人格。犬种事实与虚构人格分离，不按向量高低画出好狗坏狗。禁止抄网站形象、知名 IP、插画师专属风格、照片写实、宠物摄影、塑料 3D、复杂渐变及戏剧光影。

## 02｜身体与头身比例

统一基础画布 1024×1024；比例可比较，但不统一解剖模板。定义 H 为不含耳毛的颅顶到下颌高度，站姿地面到颅顶的高度作为头身比；坐姿仍依据站姿骨架推导，不能按坐姿高度重新缩腿。一般角色总高约 3–4.5H，头部可相对真实形态放大约 10–15%，不做占身体一半的婴儿头。短腿、视觉猎犬、巨型犬依据形态单独调整。

第一批设计目标（为插画比例指导，不是犬业协会体态标准）：

| Breed ID | 犬种 | 站姿高度参考 | 轮廓首要差异 |
|---|---|---|---|
| B001 | 柴犬 | 约 3.3H | 紧凑躯干、小三角立耳、背上卷尾 |
| B002 | 西伯利亚哈士奇 | 约 4H | 腿较长、楔形头、浓密尾，不画柴犬式紧卷尾 |
| B003 | 金毛寻回犬 | 约 3.8H | 稍宽口吻、垂耳、顺落饰毛与长尾 |
| B004 | 边境牧羊犬 | 约 4.2H | 轻盈骨架、较窄头、半立耳、低垂长尾 |
| B005 | 威尔士柯基犬（彭布罗克） | 约 2.8H | 长身短腿、宽基大立耳；本角色选自然长尾 |
| B007 | 贵宾犬 | 约 4.4H | 本角色选标准体型，长腿细口吻、垂耳卷毛 |

贵宾不同规格仍共用 B007；长尾柯基不新增品种记录。其余 114 种后续需先从 BREED_DATA 提取事实特征，再建立比例草图，不从这六种复制身体。真实形态资料尚有待核验，审核时记录参考来源；不要把本规范的夸张比例当作真实体型数据。

## 03｜头部、五官和肢体

头部先定楔形、长窄形或宽方形再画五官；口吻要有侧向体积，用一块鼻梁面和一块口鼻面表现，不用贴在脸上的小圆点取代长口吻。鼻子用 ink 小多边形或柔角三角形，适当简化，不把品牌符号贴在每张脸上。

耳朵明确耳根位置、软硬和倾角；立耳保留两条外边与内耳小色块，垂耳随头部重力下落，半立耳有可读折点。保持自然耳形，不画裁耳。眼睛为小椭圆或短弧，1024 图上通常 12–22px 宽，深色为主；无巨大玻璃高光或人类睫毛，左右可有轻微表情差别但不解剖错位。

四肢先画肩胛/髋位置再画关节，前肢下段不凭空弯折；脚掌以一块轮廓加 1–2 条趾线简化。四足总数必须正确，遮挡腿仍应有合理身体连接。尾根接在骨盆后方，卷尾、镰尾、长饰毛尾、细长尾分别设计；不以通用螺旋替代。保留自然耳尾，不为审美添加断尾。

## 04｜犬种辨识方法

每只建立至少五项辨识记录：耳形、口吻、身躯长高关系、尾型、毛纹/毛长。至少三项必须是结构差异，不能五项全靠颜色。先做纯黑轮廓，再看无名称的脸部与全身；六只并排应能通过轮廓区分紧凑柴犬、长身柯基、轻盈边牧、长腿贵宾、浓毛哈士奇与垂耳金毛。无法区分时重做结构，不能只改色。

## 05｜线条与轮廓

1024px 母图外轮廓 8–12px，主用 10px；内部结构线 4–6px，表情线约 5px。线色 ink #20201D。连接与端点轻微圆润，保留有控制的不对称起伏（约 1–3px），不加双重草稿线或随机抖动滤镜。闭合填色无漏缝；肢体重叠仅保留必要接缝，避免同位置双线。缩略图减掉细纹，不简单加强锐化。

## 06｜色彩

沿用 paper #F5F0E6、ink #20201D、rust #AA3D24、acid #D8EF58、mist #C7D8DB。犬毛允许额外选取接近真实毛色的平涂色，每只 2–4 个主体色（不含 ink 线色），如金毛的赭金 #C99442 与浅金 #E7C783；这些是插画毛色，不新增 UI 品牌色。acid/mist 用于编辑背景或后期版面，不把所有狗染成品牌色。白毛用暖白填色且保留真实不透明像素，不能把白毛误删为透明。色盲/灰度下仍须可辨轮廓和毛纹大关系。

## 07｜毛发与材质

短毛用整洁大轮廓及少量转折；双层毛在颈、胸、尾各加 2–4 个毛簇；长饰毛用长短不一的平面切口；卷毛用 6–12 个有大小变化的团块建立轮廓，内部只留少量断弧。绳状、刚毛和无毛犬后续分别制定母图，不套用卷毛纹理。

纸感来自色块边缘与少量同色细粒，纹理覆盖控制在身体面积约 5% 以内，透明区域完全无纹理；禁止逐根毛、真实皮肤、油亮高光、毛毡摄影材质和投影。纹理不得遮挡眼、鼻和品种标记。

## 08｜表情与姿态

以 PERSONALITY_DATA 的角色内容选一个动作主题，不把所有特征挤进一张图。柴犬可侧目自持，哈士奇可抬爪好奇，金毛可身体微前倾，边牧可安静专注，柯基可回头观察，贵宾可轻抬下颌。此为角色演绎，不是犬种行为断言。表达冷静不等于凶恶，热情不等于愚蠢。避免露牙威胁、流泪羞辱或夸张病态喘气；不依赖衣物、电子设备或人格文字让角色成立。

## 09｜全身图

单只完整犬只、轻微三分之四视角，保留耳尖、脚掌、尾尖。所有可见像素（含线条）位于 x/y 103–921 内，即至少 10% 安全边；最长一边约 720–800px。重心一般 x=512，可微偏不超过 40px，足底约 y=860–900。长身犬以宽度适配，不能拉长腿来占满高度；高腿犬以高度适配。体型差异由解剖体现，不用同画布虚假表达所有犬只真实等大。

## 10｜报告肖像

仅 32 种正式犬格需要独立肖像交付。仍为 1024×1024，头、双耳与上胸完整，耳顶/侧边至少 103px 留白，胸部下缘收进画面，不在脸、耳、口吻上裁断。面部中心约 (512,440)，占画布宽 45–60%，长耳/长口吻优先完整保留。保持全身版眼鼻位置关系、毛纹和配色；可从高质量母图重构，不强行放大低清局部。本次六份 Prompt 都是全身测试，肖像尚未生产。

## 11｜图鉴缩略图

由审核后的全身母图派生 256×256 PNG，保持同一安全边与 alpha；网页预期 64–128 CSS px 使用，48px 下仍检查耳、口吻与尾部。减少内部纹理后再缩小，不另造一只角色。缩略图为派生物，不额外算入 120 只。未来路径 `public/assets/dogs/full/{slug}-thumb.png`，本阶段不创建。

## 12｜透明底与背景

母图真实透明 RGBA，不能用白色、米色或棋盘格假装透明。不画地面线、投影、场景、色块边框、文字或水印。检查 paper、ink、mist 三种底上的边缘，无白边、黑边或误透明毛发。需要杂志色面时在后续版面叠加，不烘焙进角色。若生成工具不能输出 alpha，必须另行批准工作流并记录去底处理与复核，不能仅改扩展名宣布透明。

## 13｜导出规格

| 用途 | 格式 | 尺寸/画布 | 要求 |
|---|---|---|---|
| 全身与肖像矢量母版 | SVG | viewBox 0 0 1024 1024 | 真实矢量路径、无外链、无脚本、无字体依赖 |
| AI 原始栅格与通用交付 | PNG RGBA | 1024×1024，sRGB | alpha、无有损压缩、不放大低清源 |
| 图鉴缩略图 | PNG RGBA | 256×256，sRGB | 来自审核母图，透明边缘干净 |
| 评审合版 | PNG | 按需要 | 标注仅在合版层，不回写透明母图 |

AI 通常提供栅格，PNG 是真实生成结果；SVG 需人工重绘/整理后才能交付，不把 PNG 嵌入 SVG 冒称矢量。本索引 SVG 路径为最终矢量计划，不代表生成工具已能直接产出。保留 PNG 同名备用；审核范围注明具体文件及版本，不以 PNG 通过代替 SVG 通过。

## 14｜命名、版本与记录

正式路径：`public/assets/dogs/full/{slug}-full.svg`、`public/assets/dogs/portrait/{slug}-portrait.svg`；同名 `.png` 为栅格交付。slug 必须逐字取自 BREED_DATA，不按犬名重新翻译。草稿不覆盖批准文件，工作名可用 `{slug}-full-v01.png`，保留在工作区审核目录；批准后再将对应版本同步正式路径。

每次生产记录 Breed ID、Prompt 版本、工具/模型版本、实际日期、操作者、参考资料来源/许可、候选文件路径、SHA256、处理步骤和审核结论。没有调用工具就写“未生成”，不得伪造 seed、工具版本或版权审查。当前仅文档 Prompt 与原生 SVG 品牌设计；不发生 AI 图像调用。

## 15｜AI Prompt 写作规范

结构固定为：角色身份与造型选择 → 耳口鼻和身体结构 → 毛发与固有色 → 动作表情 → 统一材质线条 → 画布透明底及安全边 → 禁止项。提供全名和 Breed ID 关联，但明确画面不出现文字；不传入八维数字让模型臆造性格，不使用其他艺术家/IP 名称。优先约束结构再描述气氛，使用一只狗、一个动作、一个视角。

[FIRST_BATCH_PROMPTS.md](FIRST_BATCH_PROMPTS.md) 的六个代码块是可独立使用的完整 Prompt；不得只复制犬种段而丢失公共约束。后续变体沿用同一风格版本 `DPL-ILL-1.0`，只改明确的造型参数。六只试制审核通过后才考虑其余 114 只；本阶段只写 Prompt，不调用图像工具。

## 16｜质量验收与状态

逐资产使用 PLANNED → GENERATED → REVIEWED → APPROVED；生产状态与人工审核状态分列。PLANNED=未制作/未审核；GENERATED=已有真实输出、未人工审看；REVIEWED=有人工意见但仍待批准；APPROVED=用户或指定审核者明确批准特定版本。脚本/AI 自检不是人工批准，退回时保留版本和意见，不伪造通过。本批狗狗两列均为 PLANNED。

验收必须检查：

1. 对照 Breed ID、名称、slug，核对至少五项形态，其中三项为结构；先看无标签轮廓，再看毛纹。
2. 骨架、肢体数量、耳根、尾根和眼鼻关系无错；无裁耳断尾暗示，无极端有害夸张。
3. 线宽、色数、剪纸感、有限纹理一致；六只不是同头同身换毛色。
4. 1024 正方形、安全边、全身与肖像范围、真实 alpha 和三底边缘均合格。
5. 在 1024/256/64/48px 检查可辨识性；SVG 渲染与 PNG 一致，文件无外链脚本和伪矢量。
6. 文案语义不被表情歪曲，无 IP 挪用或艺术家专属风格模仿，来源与许可记录可追溯。
7. 由人工审阅角色一致性与品牌气质；明确批准前一律不标 APPROVED。

遇到额外肢体、错品种、同模版、假透明、IP 相似或关键结构不可辨，应退回重做，不用提高分辨率或改文件名掩盖。完成本批规范与 Logo 后停止等待视觉审核，不自动进入 Phase 3。
