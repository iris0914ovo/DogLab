## 01｜当前正式风格 DPL-ILL-1.2

手绘绘本质感的原创犬只角色插画，以第一轮六图作为画风参照。深棕色自然手绘外轮廓（建议 #3B2A22，可依据自然毛色轻微变化），线条有自然粗细起伏；以有层次的毛发笔触与色块描述体积，允许自然柔和的内部阴影和轻微纸感。色彩温暖但服从各犬种自然毛色，无毛犬不套用毛发笔触。保留真实骨架和独立轮廓，表情自然有角色感，不使用统一脸型。

不能退回纯扁平几何矢量风格，也不走写实摄影、塑料3D或强烈戏剧光照。参考基准仅继承笔触、纸感、色彩与阴影组织，不复制六只犬的身体模板。无文字、道具、服装、水印、知名IP或其他插画师专属风格。此更新只改变插画风格，不引入 SaaS Dashboard、Bento 或卡片模板。

## 02｜身体与头身比例

正式交付基础画布统一 1024×1024，高清母版允许保留原始分辨率。不同犬种不要求相同身体比例，必须保留真实耳型、口吻、身长腿长、尾型与被毛特征；比例可比较，但不统一解剖模板。定义 H 为不含耳毛的颅顶到下颌高度，站姿地面到颅顶的高度作为头身比；坐姿仍依据站姿骨架推导，不能按坐姿高度重新缩腿。一般角色总高约 3–4.5H，头部可相对真实形态放大约 10–15%，不做占身体一半的婴儿头。短腿、视觉猎犬、巨型犬依据形态单独调整。

## 03｜头部、五官和肢体

头部先定楔形、长窄形或宽方形再画五官；口吻要有侧向体积，用一块鼻梁面和一块口鼻面表现，不用贴在脸上的小圆点取代长口吻。鼻子用 ink 小多边形或柔角三角形，适当简化，不把品牌符号贴在每张脸上。

耳朵明确耳根位置、软硬和倾角；立耳保留两条外边与内耳小色块，垂耳随头部重力下落，半立耳有可读折点。保持自然耳形，不画裁耳。眼睛为小椭圆或短弧，1024 图上通常 12–22px 宽，深色为主；无巨大玻璃高光或人类睫毛，左右可有轻微表情差别但不解剖错位。

四肢先画肩胛/髋位置再画关节，前肢下段不凭空弯折；脚掌以一块轮廓加 1–2 条趾线简化。四足总数必须正确，遮挡腿仍应有合理身体连接。尾根接在骨盆后方，卷尾、镰尾、长饰毛尾、细长尾分别设计；不以通用螺旋替代。保留自然耳尾，不为审美添加断尾。

## 04｜犬种辨识方法

每只建立至少五项辨识记录：耳形、口吻、身躯长高关系、尾型、毛纹/毛长。至少三项必须是结构差异，不能五项全靠颜色。先做纯黑轮廓，再看无名称的脸部与全身；六只并排应能通过轮廓区分紧凑柴犬、长身柯基、轻盈边牧、长腿贵宾、浓毛哈士奇与垂耳金毛。无法区分时重做结构，不能只改色。

## 05｜轮廓与细节线

以第一轮已获认可图像在1024px输出上的视觉重量为准，深棕手绘外轮廓主线约4–10px，内部细节约2–5px，允许顺着毛流变化，不强制矢量式等宽描边。眼鼻等深色细节可更深，但避免贴黑塑料高光。相同观看尺寸下并排比较线条力度，不让某只变成细线写实而另一只粗线图标。

## 06｜自然毛色与温暖色彩

自然犬种毛色是首要依据，品牌 paper/ink/mist 只用于合版和后续排版，不把犬只染成统一品牌色。允许为毛色、笔触和柔和阴影添加同色系层次，取消旧版2–4色硬限制；不能按像素色数判断合格。白毛和无毛皮肤保持实体不透明，不能误扣成背景。结构在灰度和无标签轮廓下仍应可读。

## 07｜毛发、阴影与纸感

短毛顺毛向轻扫，双层毛有分组毛簇与层次，长饰毛形成自然下垂轮廓；刚毛以硬质短线和眉须表现；绳状毛画独立成束的自然绳索，不能用普通长毛替代；无毛皮肤用柔和色面与轻微褶皱，不画剃毛茬。允许自然柔和的内部阴影与轻微纸感，不要求剪纸纯色平面；纸感不打穿主体alpha，不出现背景脏污、地面投影或摄影棚效果。

线条、阴影、纸感以批准的六犬基准并排检视，不把旧版覆盖百分比与暗面数值当作新风格硬阈值。每种有独立形态，统一的是绘画语言，不是躯干比例。

## 08｜表情与姿态

以 PERSONALITY_DATA 的角色内容选一个动作主题，不把所有特征挤进一张图。柴犬可侧目自持，哈士奇可抬爪好奇，金毛可身体微前倾，边牧可安静专注，柯基可回头观察，贵宾可轻抬下颌。此为角色演绎，不是犬种行为断言。表达冷静不等于凶恶，热情不等于愚蠢。避免露牙威胁、流泪羞辱或夸张病态喘气；不依赖衣物、电子设备或人格文字让角色成立。

## 09｜全身图

单只完整犬只、轻微三分之四视角，保留耳尖、脚掌、尾尖。主体包围盒最长边目标约 819px，即画布的 80%，四周保留约 10% 安全边；包含线条与自然抗锯齿边缘，完整落在约 x/y 102–922 的安全区内。目标为近似比例，不为凑足尺寸裁耳裁尾。重心一般 x=512，可微偏不超过 40px；站姿角色优先统一承重脚底基线 y≈920（含边缘），长身短腿角色若高度不足仍按宽度约 80% 等比适配并向基线对齐，不拉高腿部。基线优先、上方允许更多留白，不能为强行居中破坏比例。坐姿不强行套用站姿腿长或拉高身体；必要时可按完整轮廓居中。长身犬以宽度适配，不能拉长腿来占满高度；高腿犬以高度适配。体型差异由解剖体现，不用同画布虚假表达所有犬只真实等大。

## 10｜报告肖像

仅 32 种正式犬格需要独立肖像交付。仍为 1024×1024，头、双耳与上胸完整，耳顶/侧边至少 103px 留白，胸部下缘收进画面，不在脸、耳、口吻上裁断。面部中心约 (512,440)，占画布宽 45–60%，长耳/长口吻优先完整保留。保持全身版眼鼻位置关系、毛纹和配色；可从高质量母图重构，不强行放大低清局部。本轮12份 Prompt 都是全身测试，肖像尚未生产。

## 11｜图鉴缩略图

由审核后的全身母图派生 256×256 PNG，保持同一安全边与 alpha；网页预期 64–128 CSS px 使用，48px 下仍检查耳、口吻与尾部。减少内部纹理后再缩小，不另造一只角色。缩略图为派生物，不额外算入 120 只。未来路径 `public/assets/dogs/full/{slug}-thumb.png`，本阶段不创建。

## 12｜透明底与背景

正式 PNG 必须为真实透明背景的 RGBA，主体外部 alpha=0，主体内部（包括白毛、眼鼻、纹理和内部暗面）alpha=255，轮廓边缘保留自然抗锯齿所需的中间 alpha。不得通过全图半透明表现纸感，不得硬阈值切边导致锯齿。轮廓间真实空隙仍应透明。不能用白色、米色或棋盘格假装透明。不画地面线、投影、场景、色块边框、文字或水印。检查 paper、ink、mist 三种底上的边缘，无白边、黑边或误透明毛发。需要杂志色面时在后续版面叠加，不烘焙进角色。若生成工具不能输出 alpha，必须另行批准工作流并记录去底处理与复核，不能仅改扩展名宣布透明。

## 13｜导出规格

| 用途 | 格式 | 尺寸/画布 | 要求 |
|---|---|---|---|
| 高清源母版 | 保留工具原生格式或原始 PNG | 允许保留原始分辨率 | 保存完整源图，不以改尺寸或改扩展名伪造高清 |
| 正式全身与肖像交付 | PNG RGBA | 1024×1024，sRGB | 真实透明背景、主体内部不透明、自然抗锯齿、安全边约 10% |
| 可选矢量重绘母版 | SVG | viewBox 0 0 1024 1024 | 仅实际人工重绘后登记，无外链/脚本/字体依赖；不是本轮交付前提 |
| 图鉴缩略图 | PNG RGBA | 256×256，sRGB | 由验收后全身图派生，保留 alpha；不替代正式 1024 交付 |
| 评审合版 | PNG | 按需要 | 标注和背景只在合版层，不回写透明交付图 |

正式交付以 1024×1024 PNG 为准，替代 V1.0 的“最终 SVG＋PNG 备用”交付约定；现有六份正式产品文档不回写。高清源文件可保留原始尺寸，导出时等比缩放，再平移放入透明画布；不得分别缩放宽高、拉伸躯干或腿、压扁口吻来填满正方形。若源图过低清或结构不合格，回到绘制/生成环节，不用插值冒充高清。SVG 仅可作为真实矢量重绘的补充，不把 PNG 嵌入 SVG 冒称矢量；版本证据需明确实际格式与文件。

## 14｜命名、版本与记录

正式 PNG 计划路径：`public/assets/dogs/full/{slug}-full.png`、`public/assets/dogs/portrait/{slug}-portrait.png`；只有文件实际上传、检查通过后才能登记为实际文件。可选同名 `.svg` 只在真实矢量重绘存在时登记。slug 必须逐字取自 BREED_DATA，不按犬名重新翻译。草稿不覆盖批准文件，工作名可用 `{slug}-full-v01.png`，保留在工作区审核目录；批准后再将对应版本同步正式路径。

每次生产记录 Breed ID、Prompt 版本、工具/模型版本、实际日期、操作者、参考资料来源/许可、候选文件路径、SHA256、处理步骤和审核结论。没有调用工具就写“未生成”，不得伪造 seed、工具版本或版权审查。首轮六图已实际生成、归档并验证GitHub上传；本轮使用当前会话图像工具自动生产，保存原始PNG及Prompt、SHA256，不打印完整Base64。工具不暴露模型ID时记null。

## 15｜Prompt 与参考图

每种按 BREED_DATA 的ID/slug/事实字段编制独立造型档案与Prompt，补充合理的耳口鼻、身材、尾巴、毛色、姿态选择，并标为角色造型选择而非新增品种事实。每张只生成一只完整犬只。使用首轮六犬合版作风格参考，明确不复制其中的身体、文字或布局。新版本标 DPL-ILL-1.2，当前12种首次生产Prompt为各ID-full-v01。

法国斗牛犬保留自然可辨的短口吻但不夸张短化呼吸结构；阿拉斯加比哈士奇骨量更大、更宽厚，不能只换色；科蒙多保留长绳状白毛；秘鲁无毛犬明确选择无毛型、可见皮肤和真实躯干，不用普通短毛犬去色代替。保存失败只恢复保存，不重调用生成；明确生成失败最多3次，未知结果先核实，避免重复任务。

## 16｜质量验收与状态

逐资产使用 PLANNED → GENERATED → REVIEWED → APPROVED；生产状态与人工审核状态分列。PLANNED=未制作/未审核；GENERATED=已有真实输出、未人工审看；REVIEWED=有人工意见但仍待批准；APPROVED=用户或指定审核者明确批准特定版本。脚本/AI 自检不是人工批准，退回时保留版本和意见，不伪造通过。用户转述的 ChatGPT 审核记录单独保留，并不等于素材已落库或人工批准。首轮六图已落库且用户认可整体风格，记录style_reference_approved；新一轮仍待人工审核，肖像未制作，清单聚合状态按既定最低进度规则计算。

验收必须检查：

1. 对照 Breed ID、名称、slug，核对至少五项形态，其中三项为结构；先看无标签轮廓，再看毛纹。
2. 骨架、肢体数量、耳根、尾根和眼鼻关系无错；无裁耳断尾暗示，无极端有害夸张。
3. 线宽、色数、剪纸感、有限纹理一致；六只不是同头同身换毛色。
4. 1024 正方形、安全边、全身与肖像范围、真实 alpha 和三底边缘均合格。
5. 在 1024/256/64/48px 检查可辨识性；正式 PNG 为 RGBA、主体内部不透明、边缘抗锯齿自然；若另交 SVG，再检查渲染与 PNG 一致且无外链脚本和伪矢量。
6. 文案语义不被表情歪曲，无 IP 挪用或艺术家专属风格模仿，来源与许可记录可追溯。
7. 由人工审阅角色一致性与品牌气质；明确批准前一律不标 APPROVED。

遇到额外肢体、错品种、同模版、假透明、IP 相似或关键结构不可辨，应退回重做，不用提高分辨率或改文件名掩盖。本次已授权第三轮102种全身图连续分批生产；不覆盖前两轮18张，不生成肖像、不开发网站、不部署；完成后停止。
