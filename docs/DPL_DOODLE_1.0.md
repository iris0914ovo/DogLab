# DPL-DOODLE-1.0｜正式犬种全身插画规范

2026-11-02（Asia/Shanghai）：用户明确审核认可Doodle V01六张试稿，授权其为全项目120种犬种的统一视觉标准。本规范锁定该六图的绘画语言，替代当前生产方向，但不删除或覆盖历史DPL-ILL-1.2、V2及style-tests文件。用户参考图仅用于最初宽泛方向，正式生产仅引用本项目已批准六图，不复制第三方具体角色、姿势或造型。

## 已批准基准及版本

B001柴犬、B002哈士奇、B003金毛、B004边牧、B005柯基、B007贵宾；原始出处public/assets/dogs/style-tests/doodle-v01，已逐文件核对manifest中的SHA256和PNG解码后，原字节纳入public/assets/dogs/doodle-v01/{ID}-full.png。历史试稿清单保留当时PENDING_REVIEW，新的正式清单记录本次明确APPROVED，避免改写历史。批准范围为六份全身图及共享视觉语言，不包含未生成犬种、人格肖像或Logo。

## 锁定视觉语言

粗黑色不规则手绘外轮廓，线条有宽度变化、自然轻微抖动与毛糙边缘。五官极简：小黑点或小椭圆眼睛，无高光、复杂眼结构；黑鼻和几笔自然嘴线。大面积自然毛色平涂，轻微填色不均允许；主体通常2–4种毛色，黑轮廓另计。略夸张的头部、自然略笨拙的站坐姿，保留犬种身体差异，不强制统一头身比。毛发只以少量大轮廓起伏提示，不逐根描绘。

禁止：精致AI商业宠物插画、写实毛发、多层毛发阴影、复杂渐变、3D塑料感、玻璃眼、高光、机械平滑矢量、Logo/吉祥物化、规则几何美容球、统一模板换色。标签与编号只用于评审合版，不进入正式透明PNG。

## 犬种识别与独立设计

唯一ID/slug/中英文/体型/被毛事实来源为docs/BREED_DATA.md，并交叉检查原docs/ASSET_MANIFEST.md。每犬独立记录头形、耳形/位置、口吻、身长体宽、四肢、尾型、毛发轮廓和自然毛色。源文档未细化的典型造型为插画设计选择，不能伪装为已外部权威核验的新增犬种事实。

柴犬紧凑狐型紧卷尾，秋田宽头厚胸重卷尾；哈士奇长吻面罩松尾，萨摩耶白毛云状轮廓与背上饰尾；边牧较窄头、半立耳、低长尾，喜乐蒂细长吻与更丰富颈饰毛；柯基大立耳长身极短腿，腊肠长垂耳更低长身；贵宾细长吻修长腿与少量卷毛包络，比熊更圆紧凑。缩至128/64px并排检视，不只靠颜色判定差异。保留自然耳尾，不画裁耳断尾；无毛型不得套短毛模板。

## 输出、证据与技术QC

每犬单独1024×1024 PNG RGBA，真实透明背景，单只完整犬。耳尖、爪掌、尾尖不裁断；完整主体居中，四边目标约10%或更多。正式文件以稳定ID命名：public/assets/dogs/doodle-v01/Bxxx-full.png，slug仍保留在清单供未来网站准确关联。本阶段不修改网站引用。

原始工具PNG原样归档；1024适配只允许等比缩放与透明画布放置，不拉伸身体。处理继承已批准基准图的技术入库流程：移除alpha<=2残留；腐蚀后主体内部及alpha>=250置255；保留其余轮廓抗锯齿。原始尺寸、包围盒、比例、位置、处理方法与原图/交付/Prompt SHA256全部记录。不能用白底或棋盘格伪造透明。若无法取得原生有效透明RGBA，暂停该图排查，不冒称合格。

记录实际工具、源路径、时间、完整Prompt、引用图与SHA256；模型ID/seed未提供时记null。技术检查包括实际解码、PNG/RGBA/尺寸、透明区、主体核心不透明、抗锯齿、安全留白、重复二进制/像素。AI并排检视解剖与风格，不能把自动检查当人工批准。

## 清单与分批边界

原版清单条目保留，Doodle独立清单覆盖120个ID，区分PLANNED、GENERATED、technical_pass、PENDING_REVIEW、APPROVED。六张基准保持APPROVED；新批次在用户确认前只能GENERATED/PENDING_REVIEW。

其余114种按ID升序排除六基准：9批各12张，最后1批6张。当前仅执行第一批B006、B008–B018。每批完整Prompt、原图、记录、12宫格paper/ink和128/64缩略检查合版、SHA256与差异化报告齐备后，正常提交推送work并独立从远程读取验证。首批完成立即暂停等用户审核；不得提前进入第二批、其余114种全量生产、人格肖像或网站修改。
