# CONTENT GUIDELINES｜内容规范 V1.0

## 1. 品牌声音

DOG PERSONA LAB｜犬格研究所是一本文字有观察力、对读者有善意的互动杂志。幽默来自日常矛盾，轻微毒舌指向行为的小尴尬，不指向人的价值。可以说“脑内会议还没散场”，不说“你就是个废物”。像认真听过朋友讲话的人，而不是发判决书的专家。简体中文为主，英文用于品牌、索引和必要术语；不把英文装饰堆成阅读障碍。

不要求每句话都有梗。标题可鲜明、正文要清楚、操作要明确。用“继续答题”“查看我的犬格报告”“清除本地记录”，不用“立即解锁命运”“不分享就亏了”。失败提示说明发生了什么和下一步，例如“这个链接的数据不完整，可以重新测试”，不责备用户。

## 2. 题目创作规则

唯一正式版本为 QUESTION_BANK 的 QB-1.0，共 24 题。D01–D08 各三题，展示顺序为三轮交错。使用最近三个月的通常反应作为回答语境，不要求用户暴露真实聊天记录、工作单位、地址或身份。

场景从群聊、AI 工具、朋友、工作边界、消费、兴趣、空间与情绪中取材。一个题干只问一次选择，避免双重问题、专业术语、道德审判、极端灾难和依赖特定付费平台的经历。使用通用的生活行为，不用流行梗作为理解前提；时间背景可当代，内容不追逐短期口号。不得把旧版直接自评句式改几个词后当作新题。

改题必须注明题库版本、影响维度与变更原因；重做计分校验，不静默套用旧进度。上线前的用户试读与测量校准属于后续验证，不因文档完整就宣称完成。

## 3. 选项与计分

每题四个自然且互斥程度合理的行为选项，分别映射 0、1、2、3，计入唯一维度。展示顺序打乱分值，但版本内固定。四个选项在长度和语气上尽量接近，不把高分写得光彩、低分写得羞耻。无需“全都符合”“以上都不是”这类破坏映射的选项。

低社交续航不等于社交无能，边界明确不等于自私，慢恢复不等于脆弱，内敛不等于没有主见，熟悉偏好不等于保守落后，慢启动不等于懒，秩序需求高不等于控制狂，暂时退场不等于不在乎。任何选项不得暗示某端人格更健康。

分值在维护文档可见，用户答题界面不可见。禁止为了让某犬格更常出现而暗改某一选项分数。计分与匹配只能按 PRD 及 PERSONALITY_DATA 的补充约定实现。

## 4. 人格报告写作

每型包含身份、称号、台词、核心描述、恰好三个标签、优势、隐藏属性、容易踩的坑、社交、情绪、关系模式与相处建议。称号概括行为机制，台词能独立分享；不要只把犬种名称代入相同段落。

描述优先用“你可能”“你更倾向于”，避免“你永远”“你注定”。优点与代价来自同一种行为倾向，让共鸣有依据。建议应可执行，例如“先确认对方想被听见还是一起想办法”，不用“你要变得更好”。结果页可以对源文案做适度连接，但不能改变向量和角色含义。

三个标签不作道德评级。犬格无稀有度、优劣、智力、财富、成功或受欢迎排行。不要制造所谓最适合结婚、最不值得交往的类型。相近角色必须在行为动机、表达方式、关系处理或行动节奏上区分；上线前进行并排试读，发现重复需说明后编辑，不靠替换同义词掩盖。

## 5. 犬种资料规范

事实字段与拟人化字段在数据和展示上明确分开；事实写形态、毛发、体型，不写“天生适合内向的人”之类推论。犬种有个体差异，真实行为受到健康、经历、环境及训练影响。不能把娱乐结果作为购买、繁殖、饲养或弃养建议。

犬种分类是网站编辑索引，不自称统一权威分类。英文名称和 slug 以 BREED_DATA 为准，别名搜索可后续扩充但不新增重复记录。涉及品种变体的收录粒度遵循该文档，不能为凑 120 条拆分同一规格。资料不确定时省略具体年代、国家、寿命数值及健康比例，不补造历史。事实变更记录核验来源及核验日期，当前参考入口不等于逐条核验完成。

健康信息保持克制且不诊断；不美化呼吸困难、不推崇极端体型，不把裁耳断尾当作审美要求。插画不应强化有害形态。

## 6. 娱乐边界与隐私

所有页面避免医疗、临床、科学验证或人格诊断暗示。不声称替代心理咨询，不将匹配度解释成概率、准确率或现实亲密关系成功率。同频与互补只是八维距离的娱乐性表达。

在关于页完整展示以下 PRD 原文，并在答题入口和结果页提供可见的简短入口：

> 犬格研究所是一款娱乐性人格测试。测试结果由用户对生活情境的选择生成，用于趣味性人格表达和社交分享，不属于专业心理测评或心理诊断。犬格人格是对犬种形象的拟人化创作，不代表所有真实犬只的个体性格。

只在浏览器本地处理答案，不收集身份。不使用迫使分享、制造焦虑或以结果交换联系方式的文案。分享链接含八维分数，提示“链接会公开你的这份结果，请自行选择是否分享”，不宣称链接完全不含个人倾向信息。清除记录操作说明范围，并对会丢失的本地答题进度做明确确认。

## 7. 禁用与审核

禁用：人格障碍等诊断标签、精神疾病玩笑、智力羞辱、身材羞辱、地域/性别/职业歧视、性暗示、恶意攻击、物化、血统优越、劝人放弃治疗、宿命论和伪造专业背书。轻微调侃不以弱势群体或创伤经历为笑点。

审核顺序：来源和版本 → 计数与 ID → 分值与向量 → 语义方向 → 文案差异 → 娱乐边界 → 移动端可读性。机械校验通过不等于内容永远无争议；后续用户反馈应记录具体原句及问题。正式发布前检查截取分享文案后是否仍保留善意，不能在整段里温和、单句海报里却像辱骂。
