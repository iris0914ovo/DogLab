## 生产与技术结果

本批13次实际image_gen调用：12种首次生成各一次，B010因轮廓过近柴犬修订一次。未重新生成六基准，无额外品种、肖像或网站。完整Prompt由BREED_DATA结构化提取事实加每犬独立形态设计形成；仅引用本项目已批准基准，不调用第三方画师截图作为直接模板。引用文件/哈希、工具源路径、实际保存时间、原始尺寸与处理参数均记录；工具未暴露模型ID或seed，记null。

12/12通过：PNG实际解码、1024×1024、RGBA、外部alpha=0、核心不透明、自然边缘中间alpha、四边至少100px、无二进制/像素重复。完整耳足尾在画布内，未见明显额外肢体；自然遮挡与坐姿不等同漏画。自动QC无法独立证明一张只一只犬、解剖或风格正确，这些另由AI视觉检查记录并等待人工批准。

交付只对原图等比适配最长边816px、居中放透明画布，移除alpha<=2残留，腐蚀主体内部及alpha>=250置255、保留其他边缘抗锯齿；原图不改。处理与已批准基准的入库技术一致，不拉伸身体、不重画五官、不以白底或棋盘格冒充透明。SHA256索引位于上级SHA256SUMS。

B010首稿为红白狐型站姿，与柴犬过近；修订改为宽头小耳、厚颈胸、粗前肢与坐姿，毛色仍自然赤褐/乳白，不改犬种分类。首稿原图、candidate-v01.png、prompt-v01.txt及record-v01.json均保留，当前B010-full.png是v02，当前Prompt与记录指向实际修订调用。
