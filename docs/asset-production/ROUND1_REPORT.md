## 技术检查

六张正式候选全部可解码为 PNG，1024×1024、RGBA、真实 alpha=0 背景、主体核心 alpha=255、自然半透明边缘，主体最长边约819px，最小安全边102px。原图主体存在近不透明 alpha=253 等数值，本批对 eroded 主体内部和近不透明值做规范化，保留边缘抗锯齿；极低 alpha<=2 的残留像素被清理，未做扣白或伪去底。原始数据不改写，处理记录可追溯。站姿底线 y=921，金毛坐姿单独居中。

文件和像素 SHA256 无重复。颜色聚类、深色像素比例及轮廓近似哈希是辅助信号，不能证明物种识别或画风完全符合规范。部分源图接近原画布边缘，正式版增加安全留白不能证明原始轮廓绝无缺损；已在记录中标 source_alpha_touches_canvas，需看图审核。
