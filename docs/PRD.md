# 01. 产品概述

## 1.1 产品定位

DOG PERSONA LAB（犬格研究所）是一款将人类性格、行为习惯、情绪反应和社交模式映射为不同狗狗品种的娱乐性人格测试网站。

用户通过回答 24 道生活情境题，系统分析其八个性格维度，并从 32 种原创犬格中匹配出最符合其行为倾向的一种狗狗。

最终，用户获得一份专属的「犬格人格报告」。

这不是传统心理测评，也不是养狗推荐工具，而是一个融合互联网文化、日常生活观察、人格趣味分类和原创角色设计的互动娱乐产品。

## 1.2 核心创意

**如果人的性格是一只狗，你会是哪一种？**

每一种狗狗都被赋予独立的人格设定。

例如：

- 柴犬：有自己的节奏，不喜欢被安排，边界感很强。
- 哈士奇：情绪表达丰富，脑回路偶尔不受控制。
- 金毛：擅长照顾别人，有时忘了照顾自己。
- 边境牧羊犬：思维高速运转，总觉得还有事情没做完。
- 柯基：外表看起来很好相处，内心其实有很多小算盘。

这些只是创作方向，最终 32 种犬格必须具有独立、完整的人格结构，不能仅仅依靠犬种的常见刻板印象来编写。

## 1.3 产品目标

用户完成测试后，应产生以下体验：

1. 题目有趣，愿意认真回答。
2. 题目场景真实，能够联想到自己的日常生活。
3. 选项之间没有明显的正确答案。
4. 测试结果具有惊喜感和辨识度。
5. 人格分析能够产生共鸣。
6. 每一种犬格都有值得分享的内容。
7. 用户愿意查看其他犬格，比较自己和朋友的结果。

核心传播动力：

**「这也太像我了。」**

## 1.4 目标用户

主要面向喜欢以下内容的互联网用户：

- 趣味人格测试。
- 社交媒体互动内容。
- MBTI、SBTI 等人格分类文化。
- 动物拟人化角色。
- 网络文化和生活方式话题。
- 个性化测试结果分享。
- 有趣的视觉内容。

不设置严格年龄限制，但内容表达以年轻互联网用户的阅读习惯为主要设计参考。

# 02. 产品核心结构

网站分为五个主要模块：

| 模块 | 主要功能 |
|---|---|
| 首页 | 品牌介绍、测试入口 |
| 人格测试 | 24 道情境题 |
| 人格报告 | 32 种犬格匹配、八维分析 |
| 犬种图鉴 | 120 种犬种浏览 |
| 关于我们 | 测试原理、免责声明 |

核心使用路径：

首页 → 开始测试 → 完成 24 道题 → 计算八维分数 → 匹配犬格 → 查看人格报告 → 分享结果 → 浏览犬种图鉴。

整个流程不需要注册、登录或填写个人信息。

# 03. 八维人格体系

## 3.1 体系设计原则

八个维度用于描述用户在不同生活情境中的行为倾向。

它们不是心理疾病指标，也不是人格优劣评价。

每个维度都是一个连续区间，而不是简单的好坏二分法。

例如：

社交续航低，不代表社交能力差；社交续航高，也不代表一定喜欢所有社交活动。

测试最终呈现的是一个具有个人特点的八维人格组合。

## 3.2 八个维度

### D01｜社交续航 SOCIAL BATTERY

<text>核心问题：人与人之间的互动，究竟给你充电还是消耗你的电量？</text>

测量内容：

- 对群体活动的偏好。
- 社交之后的精力变化。
- 对陌生社交环境的适应方式。
- 对独处和陪伴的需求。

低分倾向：独处回血型。

- 喜欢熟悉、舒适的社交环境。
- 社交时间过长容易感到疲惫。
- 更重视少数高质量关系。
- 需要私人时间恢复精力。

高分倾向：群体充电型。

- 容易从互动中获得能量。
- 喜欢参与多人活动。
- 对新社交环境相对开放。
- 容易成为群体中的活跃成员。

### D02｜边界雷达 BOUNDARY RADAR

核心问题：你允许别人进入自己生活的范围有多大？

测量内容：

- 拒绝他人的能力。
- 对私人空间的保护程度。
- 对临时要求的接受程度。
- 面对越界行为时的反应。

低分倾向：弹性接纳型。

- 比较容易配合他人的安排。
- 不喜欢让别人感到尴尬。
- 有时会先考虑别人的需求。
- 对私人边界的表达相对委婉。

高分倾向：边界明确型。

- 清楚区分自己的时间与他人的需求。
- 不喜欢未经允许的干涉。
- 能够明确表达不愿意的事情。
- 不会因为别人不高兴就轻易改变原则。

### D03｜情绪回弹 EMOTIONAL RECOVERY

核心问题：当生活突然给你来一拳，你需要多久才能重新恢复状态？

测量内容：

- 面对压力的恢复方式。
- 对负面事件的持续关注程度。
- 情绪变化后的调整习惯。
- 面对意外情况时的心理适应。

低分倾向：慢慢消化型。

- 需要一定时间整理情绪。
- 容易反复思考某些经历。
- 更倾向于独处或寻找熟悉的支持。
- 不喜欢被催促着立即恢复正常。

高分倾向：快速切换型。

- 通常能够较快调整状态。
- 更愿意把注意力转移到解决问题上。
- 不容易长时间停留在同一件烦心事中。
- 面对小型挫折时适应较快。

注意：高分不代表压抑情绪，低分也不代表情绪不稳定。

### D04｜表达外放 EXPRESSION STYLE

核心问题：你的想法和情绪，会有多少直接表现出来？

测量内容：

- 情绪外显程度。
- 对观点的表达习惯。
- 对公开表达的舒适程度。
- 对个人感受的分享意愿。

低分倾向：内敛观察型。

- 习惯先思考再表达。
- 不一定会立即展示情绪。
- 更倾向于通过行动表达在意。
- 不喜欢过度暴露私人感受。

高分倾向：外放表达型。

- 更愿意直接表达想法。
- 开心或不满通常比较容易被看出来。
- 喜欢通过语言、表情和互动表达自己。
- 不太介意成为注意力中心。

### D05｜探索欲 CURIOSITY DRIVE

核心问题：面对未知和新鲜事物，你有多容易被吸引？

测量内容：

- 对新体验的兴趣。
- 兴趣切换倾向。
- 对陌生事物的接受程度。
- 对信息和知识的探索意愿。

低分倾向：熟悉舒适型。

- 喜欢熟悉的生活节奏。
- 更重视稳定和可预测性。
- 不会因为流行就轻易尝试新事物。
- 对已经喜欢的东西有持续偏好。

高分倾向：新鲜探索型。

- 容易被新鲜事物吸引。
- 喜欢尝试不同体验。
- 经常产生新的兴趣。
- 对未知领域具有较高好奇心。

### D06｜行动启动 ACTION INITIATION

核心问题：从产生想法到真正开始行动，你需要多少启动时间？

测量内容：

- 行动启动速度。
- 对不确定性的容忍程度。
- 执行任务的习惯。
- 面对复杂任务时的推进方式。

低分倾向：预热准备型。

- 倾向于先收集信息。
- 需要一定的准备时间。
- 更喜欢明确目标后再开始。
- 有时会在准备过程中不断优化计划。

高分倾向：快速启动型。

- 容易把想法转化为行动。
- 愿意边做边调整。
- 面对新任务时通常不需要太多启动时间。
- 更喜欢通过实践寻找答案。

注意：该维度测量行动启动倾向，不直接等同于自律、工作能力或执行质量。

### D07｜秩序需求 ORDER PREFERENCE

核心问题：你更喜欢一切按照计划发生，还是接受生活随机展开？

测量内容：

- 对计划的依赖程度。
- 对变化的接受方式。
- 对生活环境的组织习惯。
- 对不确定性的容忍程度。

低分倾向：即兴自由型。

- 喜欢灵活安排。
- 不一定严格按照时间表生活。
- 能够接受临时变化。
- 不会因为环境稍显混乱而特别焦虑。

高分倾向：规划掌控型。

- 喜欢提前安排事情。
- 重视任务顺序和时间节点。
- 更习惯有计划地完成目标。
- 面对突然变化时需要重新整理安排。

### D08｜关系修复 RELATIONSHIP REPAIR

核心问题：当关系出现误会、分歧或不舒服的情况时，你会如何处理？

测量内容：

- 面对冲突时的反应。
- 主动沟通的意愿。
- 对关系修复的重视程度。
- 对误解和分歧的处理方式。

低分倾向：冷静退场型。

- 倾向于先拉开距离。
- 不喜欢在情绪激动时争论。
- 更需要独立整理自己的想法。
- 有时会选择减少互动而不是立即解释。

高分倾向：主动沟通型。

- 更愿意直接讨论问题。
- 重视双方的理解和反馈。
- 不喜欢误会长期存在。
- 愿意主动寻找关系修复的机会。

注意：低分不代表不在乎关系，高分也不代表必须承担所有关系修复责任。

# 04. 测试系统规则

## 4.1 基本规格

- 正式题目数量：24 道。
- 性格维度：8 个。
- 每个维度：3 道题。
- 每道题：4 个选项。
- 测试结果：32 种正式犬格。
- 犬种图鉴：120 种。

## 4.2 题目创作方向

题目必须采用生活情境，不直接询问用户的性格标签。

优先采用：

- 微信和群聊。
- 工作与私人时间。
- 朋友关系。
- 深夜情绪。
- 网络社交。
- 购物和消费。
- 兴趣爱好。
- 临时计划。
- AI 工具使用。
- 个人空间。
- 生活中的突发情况。
- 社交平台上的行为。

题目应体现当代年轻人的真实生活，但不能全部依赖短期网络热梗。

## 4.3 选项规则

每道题有四个选项。

每个选项对应 0–3 分。

计分映射由后台数据控制，不在用户界面显示。

选项展示顺序不应固定为从低分到高分，避免用户猜测分值。

四个选项必须具备：

- 独立的行为倾向。
- 自然的语言表达。
- 相对接近的合理性。
- 没有明显的正确答案。
- 不通过贬低某种选择来引导用户。

禁止设计成「A 是优秀人格，D 是糟糕人格」。

## 4.4 答题交互

每次显示一道题目。

用户选择后可以进入下一题。

必须支持：

- 上一题。
- 下一题。
- 修改已选答案。
- 当前题目进度。
- 完成状态提示。
- 测试进度保存。
- 重新开始。

最后一题完成后显示查看结果按钮。

不允许遗漏题目直接计算结果。

# 05. 人格计分和匹配算法

## 5.1 单维度计分

每个维度包含三道题。

每道题得分范围为 0–3。

每个维度的原始得分范围为 0–9。

转换为百分制：

dimensionScore = Math.round(rawScore / 9 * 100)

最终得到八个 0–100 的维度分数。

## 5.2 人格向量

32 种正式犬格各自拥有八维人格向量。

例如：

[80, 35, 65, 75, 55, 82, 40, 70]

八个数字分别对应：

1. 社交续航。
2. 边界雷达。
3. 情绪回弹。
4. 表达外放。
5. 探索欲。
6. 行动启动。
7. 秩序需求。
8. 关系修复。

所有人格向量由独立数据文件维护。

## 5.3 匹配算法

采用八维绝对距离匹配。

公式：

matchScore = 100 - (Σ |userScore[i] - breedScore[i]| / 8)

结果四舍五入为整数。

匹配分数越高，表示用户的八维行为倾向与该犬格模型越接近。

32 种犬格中，匹配分数最高者为用户的主要人格结果。

## 5.4 同频犬友

排除主要人格后，选择与用户八维向量距离最近的犬格。

用于展示与用户行为倾向相似的犬格。

## 5.5 互补搭子

构建反向目标向量：

complementTarget[i] = 100 - userScore[i]

排除主要人格后，寻找与反向目标向量最接近的犬格。

用于展示在性格表现上具有互补倾向的犬格。

## 5.6 平分处理

当匹配结果相同时：

1. 比较八维总距离。
2. 仍然相同时按照固定 breed ID 排序。
3. 不使用随机数。

确保相同答案始终产生相同结果。

# 06. 人格报告页面

结果页是网站最重要的功能页面。

用户完成测试后，进入独立的犬格人格报告。

必须包含：

### 6.1 身份信息

- DOG PERSONA LAB 品牌标识。
- 人格报告编号。
- 犬种名称。
- 英文名称。
- 人格称号。
- 匹配度。
- 代表性台词。

### 6.2 人格分析

每种犬格具有独立文案：

- 核心人格描述。
- 三个性格关键词。
- 主要优势。
- 隐藏属性。
- 容易出现的小问题。
- 社交模式。
- 情绪模式。
- 关系模式。
- 相处建议。

不得使用相同模板仅替换犬种名称。

### 6.3 八维数据

采用原创数据可视化。

优先使用 SVG 雷达图。

显示八个维度名称和对应得分。

图表必须与页面整体视觉一致，不使用后台仪表盘风格。

### 6.4 关系匹配

展示：

- 最佳同频犬友。
- 最佳互补搭子。

各自显示犬种名称、角色插画和简短解释。

### 6.5 分享功能

必须支持：

- 复制结果链接。
- 下载结果 PNG。
- 浏览器原生分享。
- 重新测试。

分享链接包含结果犬种 ID 和八维分数。

不包含用户身份信息。

不得将拟人化设定描述为真实犬只的普遍性格。

# 08. UI/UX 设计原则

## 8.1 总体设计定位

原创 Editorial Design（杂志编辑式设计）。

网站应该像一本具有现代互联网气质的互动杂志，而不是传统问卷、SaaS 产品或后台管理系统。

设计重点：

- 强烈的字体层级。
- 大尺寸标题。
- 不对称布局。
- 清晰的留白。
- 鲜明的颜色对比。
- 插画叙事。
- 页面节奏。
- 富有个性的细节设计。

## 8.2 明确禁止的设计方向

禁止：

- SaaS Dashboard。
- 后台管理系统风格。
- 传统电商商品卡片布局。
- 满屏白色圆角卡片。
- 每个模块独立装入圆角容器。
- Bento Grid 拼贴式模板。
- 大量悬浮阴影。
- 统一的 AI 网站生成模板。
- 直接套用现成 UI 组件库的默认样式。

特别禁止将题目和答案全部放进独立圆角卡片。

题目区域优先采用大标题、编号、分割线、排版和色彩强调的方式呈现。

## 8.3 页面布局

首页采用杂志封面式布局。

测试页采用编辑式问卷排版。

结果页采用人物档案、海报和数据报告融合的方式。

图鉴采用索引式浏览布局，不使用传统电商商品网格作为主要形式。

## 8.4 响应式要求

必须同时适配：

- 手机。
- 平板。
- 桌面电脑。

手机端优先。

不允许出现横向溢出。

不允许字体过小。

不允许按钮难以触摸。
