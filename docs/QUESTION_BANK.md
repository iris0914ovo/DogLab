# QUESTION BANK｜正式原创题库 V1.0

本版为依据 PRD V1.0 全新创作的唯一正式题库，不继承旧版传统问卷。题目版本 `QB-1.0`。24 题按三轮交错呈现，每轮 D01–D08，避免连续暴露同一维度。下列顺序即固定展示顺序；不随机改题或改分。

## 数据约定

维度顺序固定：D01 社交续航、D02 边界雷达、D03 情绪回弹、D04 表达外放、D05 探索欲、D06 行动启动、D07 秩序需求、D08 关系修复。

每题只计入标注的一个维度，选项 A–D 各使用一次 0、1、2、3 分。分值仅为开发数据，界面隐藏；不把低分称为差答案。回答最接近最近三个月通常反应的选项，没有经历时想象最可能的选择。预计用时 2–3 分钟，不设置倒计时。

## 计分与状态规范

每维三题求和得到 rawScore（0–9），`Math.round(rawScore / 9 * 100)` 得到百分分数。答案按题 ID 存储，修改答案重新计算，不能重复累加。缺题时禁止生成结果。上一题、下一题均保留选择；最后一题选完后显示“查看我的犬格报告”。本地进度记录包含题库版本；版本变化时提示重新开始，不混用旧答案。

同频与互补算法以 PERSONALITY_DATA 的实施约定和 PRD 第 05 节为准。此题库是娱乐性创作，尚未经过心理测量效度、信度或人群校准，不宣称专业测评效果。
